# Project Instructions

## Editing policy

- **Keep all edits.** Preserve completed work exactly as it was written. Do not
  revert, undo, simplify, or "tidy away" changes that a previous edit or the
  user produced, even if a later change touches the same area.
- When extending existing code, keep prior edits intact and build on top of
  them rather than replacing them.
- Only remove or rewrite existing code when the current task explicitly calls
  for it (e.g. a refactor or a bug fix whose root cause is in that code).
